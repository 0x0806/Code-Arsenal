# Product

## What it is
Code Arsenal is a browser-based programming practice platform for learners. A learner opens a
problem, writes a solution in JavaScript or Python, and the platform runs it against real tests
in a sandbox inside their own browser. XP, levels, streaks and achievements are earned only when
every test passes.

## Who it is for
Self-taught developers, students and bootcamp learners who want hands-on practice across eight
tracks: algorithms, data structures, dynamic programming, machine learning, web development,
databases, cybersecurity and mobile development. It is an educational project; there are no
accounts and no server. Progress is stored on the learner's device.

## What is true (and must stay true)
- Every problem ships with a reference solution in both languages, and an automated test proves
  that each one passes its own tests.
- Code runs in a Web Worker (JavaScript) or Pyodide (Python) with a time limit. Nothing is sent
  anywhere.
- No invented users, scores, testimonials or "AI" claims. The mentor is a rule-based offline
  tutor and is labelled that way. Rankings are a personal ladder, not a fake global board.

## Surfaces
- **Landing page (`index.html`)** — Persuade. Explains the product with its real interface.
- **App (`app.html`)** — Operate. Dashboard, challenge list, workspace, progress, terminal, mentor.

## Voice
Plain and direct. Names things by what they are. No hype words, no emoji as decoration.

## Constraints
Static files only. No build step. Works from GitHub Pages and from a local file server. Keyboard
and screen-reader usable (WCAG AA). Light and dark themes. Reduced-motion respected.
