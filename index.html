Find the two positions whose values add up to a target.

function twoSum(nums, target) {
  const seen = new Map();
  for (let i = 0; i < nums.length; i++) {
    const j = seen.get(target - nums[i]);
    if (j !== undefined) return [j, i];
    seen.set(nums[i], i);
  }
  return [];
}

A pass means every test passed, including the ones you cannot see.

  1. Run checks the public tests

    Run shows each input, the expected value and what your code returned, so you can debug.

  2. Submit adds the hidden tests

    Hidden tests report pass or fail and nothing else, so you cannot code around them.

  3. A sandbox holds your code

    JavaScript runs in a Web Worker and Python in Pyodide, both inside an isolated frame with a time limit. A runaway loop is stopped and reported.

  4. XP only on a full pass

    A single failing test earns nothing. XP is paid once per problem, on the first complete pass.

Isolated sandbox
Your solution runs in a sandboxed frame with an opaque origin and its own content security policy, apart from the app page.
No accounts, no server
No endpoint receives your code, your results or your progress.
On your device
Progress is saved in this browser. Clearing site data clears it.
Backups you hold
Export your progress as a JSON file and import it elsewhere. Imports are validated and unknown fields are dropped.
An offline mentor
The mentor is a rule-based tutor that runs locally. It is not an AI service.
One outside download
Python runs on Pyodide, which the sandbox fetches from a public CDN the first time you use Python. Your code is not part of that request.
